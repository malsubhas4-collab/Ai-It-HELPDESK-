PROJECT OVERVIEW

AI IT Helpdesk System

An AI-assisted IT support platform concept that helps users understand common technical issues, follow basic troubleshooting steps and submit support requests.

Project objectives

Reduce time spent on common IT queriesGoal
Provide guided troubleshootingGoal
Organize requests through support ticketsGoal

Technology plan

Frontend: HTML, CSS and JavaScript
Backend (next stage): Python and Flask
Database (next stage): SQLite
AI integration (next stage): A securely connected AI API

This is a front-end prototype. Ticket records are stored in this browser only. A production version needs a backend, secure authentication, database, and live AI integration.
